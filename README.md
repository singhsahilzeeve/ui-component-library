# UI Component Library Monorepo

This monorepo uses [Turborepo](https://turbo.build/repo) to manage multiple packages.

## Apps and Packages

- `apps/web`: Next.js web application consuming the UI library.
- `packages/ui`: Shared UI component library.

## Development

- `npm run dev` - start development servers for all packages
- `npm run build` - build all packages
- `npm test` - run tests across packages
